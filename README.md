Hands-on CCNA labs built in Cisco Packet Tracer — routing, switching,
security, and troubleshooting. Every lab includes a topology diagram,
configuration files, and a detailed README.

## 🧠 Skills Covered

- IPv4 addressing & subnetting
- VLSM design
- Static routing
- RIPv2 dynamic routing
- Router security (console, VTY, SSH)
- Cisco IOS CLI
- Packet Tracer simulation
- Network troubleshooting & verification

## 🛠️ Tools

- Cisco Packet Tracer 8.x
- Cisco 2911 routers
- Cisco 2960 switches

## 🚀 How to Use

1. Clone the repo:
   ```bash
   git clone https://github.com/0x9z/Cisco-CCNA-Labs.git
   ```
2. Open any `.pkt` file in Cisco Packet Tracer
3. Read the lab's `README.md` for objectives and config
4. Verify with `ping`, `tracert`, and `show` commands
