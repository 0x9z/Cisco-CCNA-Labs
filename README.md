## 🚀 How to Use

1. Clone the repo:
   ```bash
   git clone https://github.com/0x9z/Cisco-CCNA-Labs.git
   ```
2. Open any `.pkt` file in Cisco Packet Tracer
3. Read the lab's `README.md` for objectives and config
4. Verify with `ping`, `tracert`, and `show` commands
